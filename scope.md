# Project Scope: One-Click Tailored Cover Letter Generator

## 1. Problem Statement

Job seekers spend hours writing tailored cover letters or submit generic templates that recruiters ignore.

## 2. Core Goal

A lightweight web app where a user inputs their resume and a target job description, and gets a tailored, 3-paragraph cover letter in under 10 seconds.

## 3. In Scope (MVP)

- Input: Paste resume text or upload plain-text resume files (.txt, .md).
- Input: Paste target job description & company name.
- Tone selection: Professional, Modern/Startup, Executive.
- AI Generation: Uses an LLM to map achievements to job requirements.
- Output: Editable cover letter in a clean text area.
- Actions: One-click "Copy to Clipboard" and "Download as .txt".

## 4. Out of Scope (Non-Goals)

- User accounts / authentication.
- Database / history storage across sessions.
- Automated application submission.
